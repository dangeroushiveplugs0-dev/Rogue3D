# Rendering
The rendering layer exposes backend-neutral renderer interfaces plus an optional Vulkan path.
Current Vulkan foundations include device-local morph payloads, aligned sparse Float16 packing, staging synchronization, GPU morph dispatch, device-local vertex/index buffers, and a first-pass graphics pipeline with position/normal/UV input plus material controls for base color, metallic, roughness, reflectiveness, wetness, organic, dryness, emissive and occlusion.
The graphics path is separated from platform swapchain ownership. Runtime adapters provide render pass, framebuffers, command buffers and shader modules.
Pending: runtime Vulkan device/swapchain, depth attachment, shader compilation validation on target devices, texture/sampler descriptors, normal maps, image-based lighting and BRDF refinement.
