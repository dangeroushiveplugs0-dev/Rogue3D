# Squeak3D / Gearsin Visual Identity

## Direction

Playful woodland-tech 3D workstation with a **Squirrel Girl** theme.

- Warm, friendly foundation
- Squirrel/woodland-inspired visual motifs
- Small mechanical details and tiny gears
- Compact desktop-style UI with generous touch hitboxes
- Lively but restrained motion
- Technical presentation underneath the playful surface

## Gearsin mark language

The engine name is **Gearsin**. Brand marks should favor simple, readable mechanical/woodland forms that remain recognizable at small mobile sizes. Tiny gears are secondary motifs rather than the primary mark.

## Startup animation

The startup sequence is a procedural GPU-friendly 2D effect layer:

1. The Squeak3D startup surface appears.
2. Tiny gears enter or begin subtle synchronized motion.
3. Gear clusters rotate at varied speeds and directions.
4. A restrained woodland-tech accent resolves into the Squeak3D/Gearsin identity.
5. The UI fades in.
6. Idle decorative motion settles to a low-power state.

The effect must have high, medium, low, and reduced-motion modes.

## UI motion

Effects should communicate state rather than decorate every interaction:

- Selection: short tactile highlight
- Loading: small gear activity
- Success: compact mechanical pulse
- Error: restrained warning motion
- Simulation: subtle activity indicator

All animation systems should be independently disableable.
