# RogueEngine Visual Identity

## Direction

Dark professional 3D workstation + electric green energy.

- Near-black/charcoal foundation
- Electric green primary accent
- Off-white interface text
- Restrained secondary cool accents
- Technical grids and subtle geometry
- Compact desktop-style UI with generous touch hitboxes

## Rogue R

The app mark is an original geometric **R** associated with 3D topology and energy.

It should work as:
1. App icon
2. Static splash mark
3. Animated startup target
4. Subtle editor branding

## Startup animation

The startup sequence is a procedural GPU-friendly 2D effect layer:

1. Dark screen.
2. Green glossy goo appears at an edge.
3. Goo splashes and travels along the borders.
4. Streams converge toward the logo construction points.
5. The geometric R forms from the goo.
6. The R pulses once.
7. Excess goo retracts.
8. RogueEngine UI fades in.

The effect must have high, medium, low, and reduced-motion modes.

## UI motion

Effects should communicate state rather than decorate every interaction:

- Selection: short green ripple
- Loading: edge-traveling goo/energy
- Success: small pulse
- Error: restrained warning distortion
- Simulation: subtle activity indicator

All animation systems should be independently disableable.
